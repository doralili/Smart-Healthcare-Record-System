# Frontend

This directory contains the Vue 3 demo frontend for the Smart Healthcare Security project.

## Stack

- Vue 3
- TypeScript
- Vite
- Pinia
- Vue Router
- Element Plus
- Axios

## Run

```powershell
npm.cmd install
.\run_dev.ps1
```

The script starts the Vite dev server and opens `http://localhost:5173` after two seconds.
